🐾 VetCare - Clínica Veterinária

Projeto front-end desenvolvido para a VetCare, aplicando boas práticas de HTML5 semântico, CSS3 (BEM, Flexbox e unidades relativas) e responsividade.

🛠️ Tecnologias e Conceitos

HTML5: Tags semânticas (<nav>, <section>, <details>, etc.)

CSS3: Variáveis globais (:root), Metodologia BEM, Flexbox, escala em rem e layout fluido (%/vh/vw)

Acessibilidade: Botão do WhatsApp integrado ao número do SENAI e navegação por rolagem suave (scroll-behavior: smooth)

📁 Estrutura do Projeto

├── index.html          # Interface principal
├── css/
│   ├── style.css       # Estilos globais e componentes (BEM)
│   └── responsive.css  # Media queries
└── assets/             # Imagens e ícones


🚀 Como Executar

Clone o repositório: git clone https://github.com/seu-usuario/seu-repositorio.git

Abra o arquivo index.html diretamente no seu navegador ou utilizando a extensão Live Server no VS Code.
